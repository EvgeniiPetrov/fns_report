Построить автономное Python-приложение, которое принимает локальные структурированные входные данные, формирует сообщения банка по выбранному актуальному формату ФНС, валидирует конечный XML по зафиксированному официальному XSD snapshot, безопасно публикует результат, обеспечивает идемпотентность, аудит и восстановление после сбоев; реальная УКЭП и СМЭВ подключаются через отдельные ports/adapters.
